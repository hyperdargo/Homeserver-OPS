v1.0.0 Production Release
September 18, 2026

Initial deployment of the comprehensive Server Control & Observability Center for homeserver infrastructure.

Monitored Subsystems & Capabilities:

  • Docker Containers: Live tracking of containers with real-time RAM usage, memory limits, CPU percentages, network I/O, block I/O, and per-container log inspection.
  • Hermes Agent Suite: Deep monitoring of Hermes Agent Gateway, Hermes Web, HermesBot Discord, Adventure RPG bot, and active CLI sessions.
  • Hardware Thermals & Storage: Exact NVMe SSD temperature via hwmon sensors, SATA HDD temperature via SMART, CPU package and per-core thermals, PCH chipset, and partition capacity gauges.
  • Incident Triage & Errors: Automated extraction of system journal errors (priority 0-3), Kernel Out-Of-Memory (OOM) killer events, and failed systemd units.
  • Network & Services: Real-time network service registry, systemd service supervision, and PM2 process management.
  • Design System: Pure black (#0a0a0a) operational aesthetic, high-contrast typography, zero external dependencies, responsive across mobile and desktop.
— By Hermes
